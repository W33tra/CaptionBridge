# CaptionBridge 0.0.1

Первый релиз CaptionBridge для Windows x64.

Проект создан методом вайб-кодинга при участии ИИ-ассистента; требования, практическое тестирование и решения о поведении программы оставались за автором.

## Что работает

- выбор активного аудиопотока приложения;
- запуск и остановка захвата системного звука;
- передача потока в Chrome Live Caption;
- отдельный настраиваемый оверлей с последними субтитрами;
- изменение размера окна, шрифта, прозрачности и положения;
- пользовательские шрифты;
- некликабельный режим оверлея;
- сохранение профилей расположения и оформления;
- управление положением штатного окна субтитров Chrome;
- русская проверочная аудиозапись.

## Установка

1. Скачайте `CaptionBridge.exe` из раздела Assets.
2. Убедитесь, что Google Chrome установлен и функция Live Caption включена.
3. Запустите EXE. Программа предупредит перед открытием новой вкладки Chrome.

Python и .NET устанавливать не требуется: необходимые компоненты включены в EXE.

## Важно

- EXE пока не подписан цифровой подписью, поэтому Windows SmartScreen может показать предупреждение о неизвестном издателе.
- Распознавание выполняет локальная функция Live Caption в установленном Google Chrome.
- CaptionBridge не сохраняет звук или текст и не отправляет их на внешний сервер.
