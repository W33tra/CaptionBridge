# Руководство пользователя

## Требования

- 64-разрядная Windows 10 или Windows 11.
- Google Chrome с включённой функцией автоматических субтитров.
- Приложение, звук которого требуется преобразовать в субтитры.

Релизный EXE уже содержит Python и .NET; устанавливать их отдельно не требуется.

## Первый запуск

1. В Google Chrome откройте **Настройки → Специальные возможности**.
2. Включите **Автоматические субтитры** и дождитесь загрузки языковых компонентов.
3. Запустите `CaptionBridge.exe`.
4. CaptionBridge предупредит в терминале и откроет новую вкладку Chrome.

Первый запуск одного EXE может занять несколько секунд: программа временно распаковывает встроенные компоненты.

## Захват звука

1. Включите звук в нужном приложении, например в голосовом чате, видеозвонке или проигрывателе.
2. Нажмите **Обновить список приложений**.
3. Выберите приложение с активным звуком.
4. Нажмите **Запустить захват аудио**.
5. Для завершения нажмите **Остановить захват**.

Если приложение отсутствует в списке, сначала заставьте его воспроизвести любой звук, а затем обновите список.

## Проверка субтитров

Кнопка **Проверить работу субтитров** воспроизводит короткую нейтральную запись на русском языке. Если её текст появился в штатном окне Chrome и в оверлее CaptionBridge, цепочка работает.

## Оверлей

Оверлей можно открыть, перемещать и растягивать мышью. Доступны:

- ширина и высота от 50 пикселей;
- размер и семейство шрифта;
- непрозрачность;
- режим пропускания щелчков в расположенное под ним приложение;
- возврат случайно потерянного окна на экран.

При ручном изменении размера значения ползунков обновляются автоматически.

### Пользовательские шрифты

Выберите файл `.ttf` или `.otf` и нажмите **Добавить шрифт в список**. Файл копируется в `%LOCALAPPDATA%\CaptionBridge\fonts` и становится доступен в профилях.

### Некликабельный режим

После включения режима пропускания щелчков оверлей перестаёт принимать мышь. Чтобы снова переместить или растянуть его, отключите режим на странице CaptionBridge.

### Штатное окно Chrome

Его можно:

- не перемещать;
- оставить видимым одним пикселем у правого края;
- полностью убрать за правую границу всех мониторов;
- вернуть на экран.

CaptionBridge изменяет только координаты штатного окна, но не его размер. При штатном закрытии оверлея окно Chrome возвращается на экран.

## Профили

Профиль сохраняет фактические координаты и размер оверлея, шрифт, прозрачность, режим щелчков и выбранное положение штатного окна Chrome. Профили хранятся локально в профиле браузера.

## Завершение работы

После закрытия последней вкладки CaptionBridge локальный сервер и оверлей завершаются примерно через три секунды. Программу также можно остановить сочетанием `Ctrl+C` в терминале.

## Конфиденциальность

Распознавание выполняет локальная функция Chrome Live Caption. CaptionBridge не отправляет распознанный текст на внешний сервер, не сохраняет его в файл и не выводит в терминал. Веб-сервер слушает только локальный адрес `127.0.0.1`.

## Известные ограничения

- Нужен Google Chrome и его языковой компонент Live Caption.
- Некоторые приложения со сложной аудиоизоляцией могут не отдавать звук через Windows Process Loopback.
- EXE пока не подписан сертификатом, поэтому Windows SmartScreen может показать предупреждение неизвестного издателя.
